# Menva S - Portfolio 2026
Open index.html (keep the assets folder beside it). No build step.
- All text lives in the CFG block at the top of the script in index.html (lines marked TODO are placeholders).
- Extra character poses: drop PNGs into assets/poses/ (same canvas size, transparent) and list the names in EXTRA_POSES.
  Supported names: code, think, point, surprise, thumbs, sit, walk1, walk2 (walk1 + walk2 enables a walk-in on the landing page).
- Host free on GitHub Pages / Netlify / Vercel by uploading this folder.
